# ReviseHubSL

ReviseHubSL is a web-based learning platform designed to help students prepare for major examinations such as NPSE, BECE, and WASSCE. It provides revision tools, practice tests, and study support features in a simple and user-friendly interface.

---

## Features

- Access past questions by exam and subject  
- Take practice tests and track progress  
- Smart question generator for revision  
- Progress tracking and performance monitoring  
- Simple and easy-to-use interface
